# Privacy

The DocBunker browser extension does not collect, transmit, sell, or retain
personal data.

The extension only acts when you click **Open in DocBunker**. The browser
downloads the file through its normal flow — the extension never reads
the file bytes. The only thing sent to the DocBunker native host is the
local file path. No email content, URLs, filenames, or any other data is
transmitted anywhere.

Transfer metadata is stored only in browser session storage (Chrome/Edge)
or local storage (Firefox) and is wiped when the browser session ends or
the extension is removed. The only persistent setting is the optional
`deleteAfterOpen` toggle.

No analytics. No external services. No tracking.
